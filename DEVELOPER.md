# Живой фон «Город будущего» — передача разработчику

Нарисованная иллюстрация города, по которой ездит и летает 3D-транспорт
(Three.js). Статичный сайт: без сборки, без зависимостей npm, без внешних CDN.

- Демо: https://lubimovam048-bit.github.io/transport-city-bg/
- Та же сцена под формой регистрации: https://lubimovam048-bit.github.io/transport-city-form/
  (репозиторий `lubimovam048-bit/transport-city-form`, отличия — в конце документа)

## Запуск

Модули ES не открываются по `file://`, нужен любой статический сервер:

```sh
python3 -m http.server 8000      # или npx serve, или любой nginx/CDN
```

Открыть http://localhost:8000. Сборка не нужна — это готовые файлы для хостинга.

Параметры адреса для разработки:

| Параметр | Что делает |
|---|---|
| `?debug` | рисует траектории всех маршрутов и линию горизонта поверх сцены, выводит `window.__scene` |
| `?t=12` | стоп-кадр на 12-й секунде (скриншоты, проверка одного момента) |

## Состав

```
index.html        разметка: фон, canvas для 3D, вырезанные слои поверх 3D
scene.js          вся логика сцены (~450 строк, без сборки)
assets/
  background.webp фон 2800×1800 (исходный рисунок 1446×1087 + достроенные небо, дорога, края)
  *.webp          вырезанные слои, которые стоят перед транспортом: арка, здание, клумба,
                  фонарь, дерево, кусты; towers.webp — маска глубины небоскрёбов
  *.glb           5 моделей: bus, train, robot, drone, flyer
vendor/three/     Three.js r180 (MIT), только нужные файлы
```

Вес: ≈ 3,4 МБ файлов (модели 1,6 МБ, картинки 1,0 МБ, Three.js 0,8 МБ); при gzip/brotli на сервере по сети уходит ≈ 2,5 МБ.

## Как устроено

**Координаты.** Всё задаётся в пикселях исходного рисунка 1446×1087:
маршруты (`routes` в `scene.js`) и положение слоёв (`data-x/y/w/h` у `<img class="layer">`).
Исходный рисунок лежит внутри расширенного фона со сдвигом `OX = 688, OY = 368`
(`FULL_W × FULL_H = 2800 × 1800`). Поэтому всё остаётся приклеенным к рисунку на любом экране.

**Камера** подобрана под перспективу рисунка (`CAM`: fov 35°, высота 8 м, горизонт на y = 450 px)
и расширена `setViewOffset` на достроенные края. Пиксель → 3D: `ground(x, y)` — точка на дороге,
`air(x, y, d)` — точка на расстоянии d по лучу (для воздуха и эстакады).

**Слои.** Порядок снизу вверх: фон → canvas с 3D → вырезанные слои (`.layer`). Транспорт,
проезжающий «за» деревом или аркой, просто рисуется под слоем. Клумба и кусты справа
переключаются под/над 3D по ходу робота (класс `.behind`). Небоскрёбы — невидимая
«стена глубины» в 3D (пишет только глубину по маске `towers.webp`): летающая машина
скрывается за ними, а поезд проходит перед ними. Клумба слева — `div.occ` с `clip-path`.

**Кадрирование** (`frameStage`): фон всегда закрывает экран. Широкие экраны — по центру
исходного рисунка, высокие (телефоны) — вся высота с небом и дорогой, со сдвигом вправо.

**Анимация** — функция `update(t)`, t в секундах:

| Объект | Как движется | Где менять |
|---|---|---|
| 2 автобуса | один маршрут `shuttleA`, круг 22 с, второй на полкруга позади | `update`, `routes.shuttleA` |
| поезд | 6,45 м/с по эстакаде, пауза 2 с между поездами | `TRAIN_V`, `TRAIN_PAUSE`, `routes.train` |
| робот-доставщик | круг 26 с, разворот у бордюра | `routes.robot` |
| квадрокоптер | висит и дрейфует, лопасти полупрозрачные | `DRONE_WIDE` / `DRONE_TALL` |
| 2 летающие машины | по 14 с из цикла 30 с, ровная скорость на экране, пар под днищем | `FLY_*`, `routes.flyer` |

Маршруты — сглаженные кривые (Catmull-Rom) по точкам в пикселях рисунка. Чтобы поправить
маршрут: открыть `?debug`, сдвинуть точки в `routes`, обновить страницу.

**Производительность.** Цикл останавливается, когда сцена вне экрана (IntersectionObserver),
на телефонах ниже плотность пикселей (≤ 1,5) и меньше частиц пара. При «уменьшении движения»
в системе показывается неподвижный кадр. Ориентир: 60–120 кадров/с на ноутбуке.

## Модели

GLB со сжатием meshopt, квантованием вершин и текстурами WebP. Загрузчик:
`GLTFLoader` + `MeshoptDecoder`. Модель должна смотреть носом по +Z; размер задаётся длиной
в метрах (`loadModel(..., 'assets/bus.glb', 4.2)`).

Сжать новую модель так же:

```sh
npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 1024
```

## Встраивание

Вариант 1 — фоном страницы целиком: взять `index.html`, а свой контент положить поверх
(`position: fixed` слой с `z-index` выше `.viewport`). Так сделано на странице с формой.

Вариант 2 — в `<iframe src="…/index.html">` на нужный блок.

Кэш: GitHub Pages отдаёт файлы с `max-age=600`, поэтому при правках к ссылкам на `scene.js`
и `background.webp` в `index.html` дописывается `?v=…`. На своём хостинге можно настроить
обычное кэширование с хэшами в именах.

## Требования к браузеру

WebGL 2, ES-модули и import maps: Chrome/Edge 89+, Firefox 108+, Safari 16.4+
(iOS 16.4+). Без WebGL останется статичный фон.

## Отличия версии с формой (`transport-city-form`)

- `scene.js` дополнен паузой для кнопки «плей/пауза»:
  `window.cityScene.pause()`, `.resume()`, `.paused` — сцена замирает и продолжает с того же кадра.
- На широких экранах кадр берёт исходный рисунок крупнее (как в макете Figma).
- Поверх — форма регистрации (`form.css`, `form.js`), фон затемнён и размыт.
